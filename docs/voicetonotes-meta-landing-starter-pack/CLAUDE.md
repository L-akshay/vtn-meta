# Claude Code project instructions

Read `00_START_HERE.md` and `AGENT_MASTER_PROMPT.md` before making changes.

Treat the markdown files in this pack as product requirements.

## Working style

- Inspect before editing.
- Prefer small, coherent components.
- Do not introduce a UI framework.
- Do not rewrite working infrastructure without evidence.
- Run typecheck/lint/build after meaningful milestones.
- If a requirement conflicts with the existing codebase, explain the conflict and choose the lowest-risk implementation.
- Never fabricate missing product proof.

## Highest-priority files

- `06_FACT_CHECK_AND_CLAIMS.md`
- `04_ANALYTICS_AND_ATTRIBUTION.md`
- `07_QA_ACCEPTANCE.md`

## Definition of “premium”

Premium means strong hierarchy, typography, spacing, real product imagery, and controlled motion.

It does not mean adding more visual effects.
