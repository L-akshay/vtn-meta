## Campaign purpose

This is not the corporate website.

It is a short, premium, high-intent destination for Meta ads. A visitor should understand the product in roughly three seconds and have an obvious way to install it.

### Primary action

Every primary CTA, sticky CTA, store badge, and permitted page click sends the visitor to the smart link.

### Secondary actions

Only footer legal/store text links are direct URLs.

There is:
- no main navigation
- no login
- no pricing
- no blog
- no newsletter
- no stories / novels / VTN Reads
- no feature catalog
- no SEO content

## Audience / device mix

Assume:
- 95% mobile
- significant Instagram/Facebook in-app browser traffic
- 5% desktop

The desktop version should be polished, but it must not distort mobile decisions.

## Experience principles

1. **Product first** — real VoiceToNotes UI dominates the page.
2. **One idea per viewport** — do not create a SaaS feature-grid page.
3. **One conversion** — installing/opening the app.
4. **Proof only when defensible** — no fabricated counts, badges, awards, reviews, or security language.
5. **Motion has a job** — only the hero demo and the scroll-linked showcase may move meaningfully.
6. **Quiet premium styling** — white space, typography, product screens, one black showcase section.
7. **Touch-first** — no hover-dependent information.

## Recommended section order

1. Hero + live product moment
2. Optional proof strip — only when verified
3. How it works
4. Black product showcase
5. Who it is for
6. Optional real reviews
7. Privacy reassurance
8. Final CTA
9. Footer

If proof or reviews are not supplied, remove them rather than filling the space with generic marketing content.
