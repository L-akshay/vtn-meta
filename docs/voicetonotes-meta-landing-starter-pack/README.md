# VoiceToNotes Meta landing starter pack

This pack is ready to drop into the root of the landing-page repository as planning/agent context.

## Included

- product brief
- mobile-first UX spec
- campaign copy
- analytics/attribution plan
- asset manifest
- fact-check/claims gate
- QA checklist
- implementation plan
- Cloudflare deployment notes
- Claude/Codex instructions
- starter code snippets

## Missing inputs before final production polish

- source-quality VoiceToNotes app icon
- source wordmark
- current real app screenshots
- approved brand accent hex if the icon is not the authority
- Meta Pixel ID
- approved store proof, if proof is desired
- approved real reviews, if reviews are desired
- verified publication/profile links if “Featured on” is desired

The site can be coded without these, but unverified sections should stay hidden.
